# 박사학위 콘솔

공공정책학 박사 프로포절 **36주 실행 콘솔**. 주차별 과제, 투입 시간, 매달 규율을 한 곳에서 추적합니다.

**→ https://jyseok0311.github.io/phd-console/**

## 화면

| 화면 | 하는 일 |
|---|---|
| **오늘** | D-day, 이번 주 과제 체크, 투입 시간, 이번 달 규율, 다음 지도교수 접점 |
| **보드** | 36주 전체 보드(완료/이번 주/기한 지남/예정), 주차 상세와 회고 작성 |
| **기록** | 주간 투입 시간 차트, 주차별 기록 목록, 회고 `.md` 내보내기, 전체 백업·복원 |
| **참조** | 월별 계획, 학업 마일스톤, 운영 규칙과 근거 연구 |
| **목차** | 논문 1~5장 목차(절·항 43개)와 진행 상태(미착수→완료 5단계), 절별 작성 쪽수·목표 쪽수, 메모, 36주 계획 주차·작성 문서 연결, 목차 `.md` 내보내기 |

## 저장

기록은 **이 브라우저의 localStorage**에만 저장됩니다. 서버로 전송되지 않습니다.
기기를 옮기거나 캐시를 지우기 전에 `기록 → 백업`에서 `.json`으로 내려받으세요.

## 구조

의존성 없는 단일 파일(`index.html`). 빌드 도구 없음, 외부 요청은 Google Fonts와 같은 저장소의 `data/thesis.json`뿐.

- `data/thesis.json` — 데이터 화면이 열릴 때 한 번 불러오는 논문 패널 요약(약 0.8MB). 공개 공시·통계(대학평가원 대학현황지표, 대학알리미, KESS, 대학재정알리미, KERIS, 장학재단, 교육부 보도자료, KOSIS)의 집계값과 학교별 주요 변수만 담고, 원자료·스크립트·정제 로그는 비공개 논문 저장소의 `build_console_data.py`가 생성합니다. 파일을 직접 열면(`file://`) 브라우저가 fetch 를 막으므로 데이터 화면은 Pages 주소에서 봅니다.

- 36주 시작일은 `START` 상수(2026-09-14) — 모든 날짜와 D-day가 여기서 계산됩니다
- 주차 과제는 `WEEKS`, 월별 계획은 `MONTHS`, 마일스톤은 `MILESTONES` 배열

## 담고 있지 않은 것

일정 추적에 필요 없는 재무·고용 관련 개인 정보(자산, 급여, 계약 조건)는 이 저장소에 없습니다.
계획 원본은 별도의 비공개 저장소에 있습니다.
